GRITLINE Aggregates — Documentation

Complete guide to installing, customizing, and deploying the GRITLINE Aggregates multi-page static website.

1. Installation & Local Preview

This website is built with pure semantic HTML5, CSS3 custom properties, and native ES6 JavaScript modules—requiring zero npm dependencies or build steps. Serve the root folder with any static web server (`python -m http.server 8080` or VS Code Live Server) and open `/index.html` or `/pages/index.html`.

2. Customizing Earth-and-Quarry Colour Variables

Open assets/css/style.css (lines 11–26) to adjust the core palette: 

:root {
  --sand-50:   #FBF6EC;  /* bleached sand (light bg) */
  --sand-200:  #EAD9B5;  /* dune */
  --sand-400:  #D2B07A;  /* river sand */
  --ochre:     #C98A2B;  /* primary accent / CTAs */
  --rust:      #B5532A;  /* secondary accent, hovers */
  --slate-900: #1B1D1F;  /* quarry black (dark bg) */
  --slate-700: #34393D;  /* crushed granite */
  --stone-500: #8A8F8A;  /* gravel grey */
  --moss:      #4F6B4A;  /* subtle success/eco accent */
}

3. Customizing Fonts, Rates & Contact Information

• Fonts: Declare self-hosted WOFF2 files in assets/fonts/fonts.css or update the Google Fonts link in the <head> of each page.
• Calculator Densities & Bulk Rates: Edit the data-density and data-rate attributes on #calc-material in pages/products.html.
• Delivery Zones: Update the ZONES dictionary in assets/js/main.js (`initDeliveryZoneSelector`).
